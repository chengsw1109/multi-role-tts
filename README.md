# 多角色配音室

以 OpenAI 的 Speech API 製作多角色台詞的本機網頁工具。金鑰只由本機 Node.js 伺服器讀取，不會傳到瀏覽器。

## 啟動

```powershell
npm start
```

開啟 <http://localhost:3000>。開發時可用 `npm run dev`。

## 使用方式

1. 在「貼上故事」區塊貼入完整故事，點選「分析故事並建立段落」。系統會將敘述設為旁白，並將 `「」` 中的文字切成對話；對話角色依前後文推測，請在產生前檢查並修改。
2. 選取「瀏覽器語音」後點選「免費試聽」，可直接使用電腦已有的語音朗讀；此模式不會呼叫 API，也不會產生 MP3。
3. 點選「產生語音」逐段生成，或「產生全部語音」。
4. 在播放器試聽後，用「下載 MP3」儲存個別音檔。

此專案預設使用 `tts-1` 與 Audio Speech API；可用的聲音選項會由伺服器端白名單驗證。
