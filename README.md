# 故事語音

完全使用瀏覽器內建語音的本機故事朗讀工具。不使用 OpenAI API、沒有金鑰、沒有費用，也不會建立或下載音檔。

## 啟動

```powershell
npm start
```

開啟 <http://localhost:3000>。開發時可用 `npm run dev`。

## 使用方式

1. 將完整故事貼到輸入框。
2. 選擇「聲音」模式、語速及電腦已有的「瀏覽器語音」。
3. 點選「語音」開始免費朗讀，再次點選可停止。

在「自動分類朗讀」模式下，系統會將敘述視為旁白、將 `「」` 中的內容視為對話，並依前後文嘗試區分說話者。若電腦只有一個對應語言的內建語音，所有段落仍會使用該聲音朗讀。
