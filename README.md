# 故事語音

完全使用瀏覽器內建語音的本機故事朗讀工具。不使用 OpenAI API、沒有金鑰、沒有費用，也不會建立或下載音檔。

## 啟動

```powershell
npm start
```

開啟 <http://localhost:3000>。開發時可用 `npm run dev`。

## 使用方式

1. 將完整故事貼到輸入框。
2. 選擇「聲音」模式、語速及電腦已有的「瀏覽器語音」。程式會優先選擇 Google 國語（台灣／臺灣）；若電腦未安裝該語音，會回退到其他台灣中文或中文語音。
3. 點選「語音」開始免費朗讀，再次點選可停止。

## 自然語調

預設開啟的「自然語調」會在朗讀前後處理文字與語氣，讓輸出更接近真人說話：

- **口語化文字**：數字、百分比、時間、溫度、負號等會轉成中文念法（`2024 年` → 二零二四年、`35%` → 百分之三十五、`12℃` → 十二度、`3:30` → 三點三十分），並移除表情符號與 Markdown 符號。
- **完整句子斷句**：優先在句號、驚嘆號、問號處分段，句子太長才在逗號處切開，語調不會每逗號就中斷。
- **語氣**：對話會依前後文（大喊、低聲、哭、笑、冷冷等）調整語速與音高；問句尾音上揚、驚嘆句加快、省略號放慢。每個角色另有固定的音高偏移，即使只有一個語音也聽得出人物差異。
- **停頓**：依標點決定句間留白，換人說話與段落結束再多留一點，避免整篇黏在一起。

關閉此選項即回到原本逐段直接朗讀的行為。瀏覽器語音會套用語速、音高與停頓；Voicebox 模式沒有音高控制，會套用語速與停頓。

在「自動分類朗讀」模式下，系統會將敘述視為旁白、將 `「」` 中的內容視為對話，並依「某某說／喊／回應」等前後文嘗試區分說話者。未標示說話者、只用代名詞或高度依賴上下文的對話，無法在完全免費的本機模式下保證判斷正確；若電腦只有一個對應語言的內建語音，所有段落仍會使用該聲音朗讀。

## Voicebox 本機多人語音（可選）

選擇「Voicebox 本機多人語音」後，程式會在背景依角色名稱選擇 Voicebox 的聲音設定檔並依序播放，無需在本頁逐一建立角色卡。先在 Voicebox 建立並下載中文語音設定檔，再將設定檔名稱命名為 `旁白`、故事人物名稱（例如 `江楓`）或 `預設`；程式會優先依角色名稱比對，找不到時使用 `旁白`、`預設` 或第一個可用設定檔。

Voicebox 必須在本機執行；預設網址為 `http://127.0.0.1:17493`，可在頁面改成你的實際本機網址。此整合只接受 `localhost`／`127.0.0.1`／`::1` 的 HTTP 位址，不會將故事傳到外網。使用有同意的台灣國語錄音建立設定檔，或使用你有權使用的預設語音。
